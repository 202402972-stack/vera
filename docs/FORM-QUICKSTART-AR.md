# تشغيل VÉRA 2.1 وFORM

المشروع يستخدم React وVite وExpress وSQLite، بنفس البنية الأصلية. يلزم Node.js 24 وnpm.

## تشغيل التطوير على Windows

```powershell
npm ci
Copy-Item .env.example .env
npm run dev
```

افتح `http://localhost:3000`. معاينة القالب الأول: `/demo/atelier`، ومعاينة FORM: `/demo/form`. لإنشاء متجر حقيقي، أكمل إعداد Google OAuth الموضح في `docs/INTEGRATIONS.md`. اختيار القالب يكون عند الإنشاء، ولا توجد عملية تبديل من لوحة التحكم.

## تجربة قابلة للتعديل دون إعداد Google

```powershell
npm run build
npm run review:form
```

افتح `http://127.0.0.1:3001/s/form-review`، ولوحة التحكم `/s/form-review/admin`. كلمة المرور المحلية: `local-review-only-123`. هذه بيانات تجربة منفصلة تحت `output/review-data`، ولا تستخدم هذا الأمر في الإنتاج. المتاجر الجديدة الفعلية في FORM تبدأ دون منتجات وهمية؛ منتجات المعاينة موسومة بوضوح.

## ما تديره لوحة التحكم

- المنتجات والصور والمخزون والخيارات، بما فيها اللون والمقاس والخامة المستخدمة في فلاتر المتجر.
- المجموعات ومحتواها وصورها العربية والإنجليزية، وهوية المتجر ورسوم التوصيل والضرائب والخصومات.
- تصميم FORM: النصوص، صورة الواجهة، موضع الصورة للديسكتوب والموبايل، صورة الحملة وإظهار أقسام الصفحة.
- الطلبات وحالتها وبيانات تتبع الشحن. حساب العميل يعرض الطلبات والتتبع والمفضلة.
- تقييمات المشتريات المسلّمة: لا تظهر للعامة إلا بعد موافقة التاجر.
- طلبات الاسترجاع والاستبدال والرد على العميل ومراحل الطلب. موافقة الاسترجاع لا تعني إتمام رد المبلغ أو إعادة القطع للمخزون تلقائيًا.
- استعادة حساب العميل: رابط يستعمل مرة واحدة وينتهي خلال 30 دقيقة، يصدره التاجر بعد التحقق من هوية العميل.

## الدفع

الدفع عند الاستلام يعمل افتراضيًا. للدفع الإلكتروني، اضبط بيانات Paymob الخاصة **بالمتجر** من تبويب المدفوعات، مع عنوان HTTPS في `PUBLIC_URL`. بيانات اشتراك منصة VÉRA في ملف البيئة مستقلة عن دفع المتسوق.

التكامل يتحقق من توقيع إشعار Paymob ثم يعيد قراءة المعاملة من المزود ويطابق المبلغ والعملة والطلب. الرجوع من صفحة الدفع وحده لا يؤكد الدفع. تم فحص العقد محليًا باستجابات مزود محاكية؛ يلزم اختبار حساب التاجر التجريبي قبل بدء التحصيل الحقيقي.

للتشغيل الإنتاجي، اتبع `docs/RAILWAY.md` واحتفظ بنسخة احتياطية من قاعدة البيانات والصور ومفتاح التشفير معًا.
