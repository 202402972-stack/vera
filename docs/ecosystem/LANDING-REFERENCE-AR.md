# مراجعة اللاندنج وفق مرجع Pixells — 10 أكتوبر 2026

## النطاق والمراجع

التغييرات تخص الصفحة الرئيسية `/` فقط، بما فيها الهيدر والفوتر ومعاينات المتاجر والإدارة المعروضة فيها. ملفات المتاجر ولوحات التاجر والمالك والسيرفر والدومينات لم تتغير. الأساس هو commit `aa012ad` على `codex/vera-ecosystem`.

- فتح `https://pixells.co/en` في Chromium بعرض 1440 و390 بكسل، وقراءة التنسيقات المحسوبة والحركات أثناء التمرير.
- استخدام صور المستخدم الكاملة والمفصلة للديسكتوب، وصورة التايملاين على الهاتف.
- الصفحة الأساسية متاحة؛ مضيف الصور `media.pixells.co` كان يرجع رفضًا من وكيل الشبكة أثناء المراجعة. صور المستخدم عوّضت الصور المحجوبة. لم نستخدم صور Pixells أو شعاره داخل VÉRA.

التطبيق يعيد لغة المرجع البصرية مع محتوى VÉRA. لا يُدّعى تطابق كل بكسل أو كل حركة في Pixells؛ طول المحتوى وتوزيع الميزات مختلفان. الخطان الإنجليزيان Playfair Display وRaleway محليان ومرخّصان في المشروع، والعربية Amiri وTajawal. خط التنقل الخاص بالمرجع Gotham Narrow لم يُنسخ.

## التحقق

- `npm run lint`: نجح.
- `npm run build`: نجح.
- اختبارات اللاندنج: **12 نجحت**، منها 4 جديدة لاختيار القوالب، تزامن الصور والروابط، التمرير الأفقي بالعربية والإنجليزية، نسبة صورة الإدارة، وانتهاء تأثير CSS اللاندنج عند الانتقال لتسجيل الدخول.
- فحص مستقل في المتصفح: **12 حالة** = لغتان × عروض 320، 360، 390، 768، 1024، 1440. لا تجاوز أفقي، ولا عناوين أو أزرار يتجاوزها النص، ولا صور مرئية مكسورة، ولا أخطاء JavaScript أثناء الفحص. [النتائج](evidence/landing-reference/responsive-checks.json).
- مراجعة صور كل الأقسام باللغتين عند 390 و1440. صور التسليم التقطت مع تقليل الحركة وبعد تحميل صور الصفحة؛ لا تمثل اختبارًا لسرعة الشبكة. فحص الحركة تم منفصلًا.
- الاختبارات القائمة المختارة تشمل أيضًا التأكد من سلامة مقاييس لوحة المالك وتنقل GALA على الهاتف. لم يتم توسيع الفحص إلى وظائف الدفع أو الدومينات لأنها خارج هذه التغييرات.

## التشغيل

```bash
npm ci
npm run dev
```

لإعادة الفحوص في بيئة Chromium الحالية:

```bash
npm run lint
npm run build
PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium \
PLAYWRIGHT_SKIP_FONT_READY=1 \
npm run test:platform:e2e -- --grep 'landing'
```

يُشغّل Playwright سيرفرًا مؤقتًا ببيانات تجريبية مستقلة. لا يحتاج عرض اللاندنج إلى تفعيل Google أو Paymob أو خدمات الدومينات. التغييرات مخصصة للفرع الحالي دون دمج أو نشر إنتاجي.
