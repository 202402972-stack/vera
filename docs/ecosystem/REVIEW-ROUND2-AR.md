## التحقق وطريقة التشغيل

شُغّل التطبيق محليًا بـ`npm run dev`، وفُحصت العربية والإنجليزية على 360 و390 و430 و768 و1440px بحسب الشاشة والرحلة؛ فُحص تجاوز العرض وأخطاء JavaScript. `npm run lint` و`npm run build` ناجحان. اختبارات المنصة الجديدة والحالية: **51/51 في التشغيل الشامل**، مع فحص إضافي لانتقال FORM إلى محرر الشعار؛ اختبارات المتجر القديم: **26 حالة ناجحة** عبر التشغيل الكامل وإعادة حالتي القائمة بعد إزالة Brand المكرر في Atelier. صور fixture لا تختبر Google/Shopify/Woo/Paymob/Stripe الحقيقية.

```bash
npm ci
npm run dev
# افتح http://localhost:3000
npm run lint
npm run build
PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium PLAYWRIGHT_SKIP_FONT_READY=1 npm run test:platform:e2e
PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium PLAYWRIGHT_SKIP_FONT_READY=1 npm run test:e2e
```

## المتبقي خارج البيئة المحلية

Google OAuth لحساب مستخدم فعلي، مصدر Shopify/Woo مصرح به مع اتصال DNS/egress، واعتماد خطة مزود الدفع وتجربة success/failure/webhook حي، ثم تجهيز أسرار الإنتاج وHTTPS ونسخة خارجية وتنبيه ومراجعة إطلاق. شرح الخطوات والمتطلبات في [OPERATIONS-AR.md](OPERATIONS-AR.md). لم أدّعِ نجاح هذه المسارات عبر صور fixture أو وجود الكود فقط.
