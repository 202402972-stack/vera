# ڤيرا 2.1 — منصة المتاجر

أضيف قالب FORM بواجهة عصرية مستقلة، ولوحة تصميم مرتبطة بصور المتجر، وحسابات المتسوقين والمفضلة والتقييمات والاسترجاع والاستبدال. لوحة الإدارة المشتركة تدعم القالبين. [دليل التشغيل وتجربة المتجر محليًا](docs/FORM-QUICKSTART-AR.md) يشرح البدء على Windows وإعداد دفع Paymob الخاص بكل متجر، المستقل عن اشتراك المنصة.

نسخة واحدة على Railway تشغّل اللاندنج، حسابات Google، مساحة العميل، لوحة المالك، والمتاجر ولوحات إدارتها. المتاجر مستقلة في البيانات والإعدادات والصلاحيات، داخل قاعدة بيانات واحدة.

- الصفحة الرئيسية: `/`
- القوالب: `/templates` — المعاينة الحية: `/demo/atelier` و`/demo/form`
- دخول العميل: `/login` — مساحته: `/workspace`
- لوحة المالك: `/owner`، وصلاحيتها للبريد الموجود في `OWNER_EMAILS` فقط.
- كل متجر: `/s/اسم-المتجر` ولوحته `/s/اسم-المتجر/admin`.
- الخطة المعلنة: ١٫٥٠ دولار شهريًا للمتجر. تجربة ١٤ يومًا من إنشاء الحساب، لا تتجدد بإنشاء متجر آخر.

ابدأ بـ `npm ci` ثم انسخ `.env.example` إلى `.env` وشغّل `npm run dev`. بدون مفاتيح Google يمكنك تصفح الموقع والقالب؛ لا يوجد دخول وهمي أو حساب افتراضي للمنصة.

تعليمات النشر موجودة في [docs/RAILWAY.md](docs/RAILWAY.md). يلزم ربط Google OAuth وحساب Paymob المصري وتفعيل الاشتراكات المتكررة على حساب التاجر. سعر وعملة التحصيل الفعليان يظهران قبل الدفع، ولا يتم تحويل الدولار تلقائيًا لسعر جنيه مفترض.

المتجر يحتفظ بتصميمه الأصلي، مع مجموعات متعددة، تخصيص الهوية، الطلبات والمخزون والخصومات والشحن والتحليلات. يمكن تغيير كلمة مرور إدارة المتجر من مساحة العميل أو من صفحة التكاملات والأمان داخل لوحة المتجر. لا تُعرض كلمة المرور القديمة لأنها محفوظة كـ hash.

اللوجو: `public/platform/assets/vera-mark.svg`.
صورة البروفايل: `public/platform/vera-profile.png` بحجم 1080×1080.

الاختبارات المحلية لا تعني أن النشر أو تحصيل الدفع الفعلي قد تمّا. راجع [التكاملات](docs/INTEGRATIONS.md) و[نتائج التحقق](docs/VALIDATION.md) قبل فتح التسجيل العام.
